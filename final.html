Making car radar ignore ghosts
and stay aligned

A plain-English tour of the A-PRISM upgrade to our radar tracker — what was wrong, what we changed, the bugs we caught along the way, and the tests that prove it works.

01 ◆ The story in 60 seconds

Radar sometimes sees things that are not really there, and slowly drifts out of alignment — like a crooked picture frame. We taught it to spot the fakes and straighten itself. Everything new is switched off by default, so today's behavior cannot change until someone deliberately flips the switch.

◆ The mirror ghost

A radar wave can bounce off a guardrail, hit a car, and bounce back — the radar then "sees" a phantom car behind the rail. Before, the tracker could brake for nobody.

◆ The crooked frame

Sensors slowly tilt with vibration and temperature. A few degrees of tilt means meters of error at distance. We feed the measured tilt back in automatically.

◆ The spray blur

Rain and road spray make detections noisy. We measure that noisiness and trust blurry data less instead of treating all data equally.

02 ◆ What we changed

Nine upgrades across two codebases. Each card is the plain version — open the technical note for file names engineers can click through.

TRACKER OT-1

Use the ghost as a witness

Instead of deleting a suspected ghost echo, the tracker listens to it carefully (with extra uncertainty) to sharpen the real car's speed estimate.

Technical notef360_msmt_update_obj_trks_cca_moveable.cpp + ..._ctca.cpp: append/inflate one ghost range-rate row, Reff = R + (2σ)2; XOR sidecar marks the track.
TRACKER OT-2

Mirror geometry check

A real reflection must obey mirror geometry exactly. Pairs that fail this math identity test are rejected as impostors.

Technical notef360_is_reflective_guardrail_track.cpp: rank-1 invariant |g − s − 2dn| ≤ 1.0 m, else reject.
TRACKER OT-3

Wider net for fast cars

Hard-accelerating cars can jump out of the tracker's search window. The window now stretches with acceleration — but never beyond safe, pre-approved limits.

Technical notef360_determine_association_hypothesis.cpp: adaptive γ ∈ [9.21, 40], Doppler de-aliasing untouched.
TRACKER OT-4

Curved rails count too

Guardrails bend. A second, curved-rail hypothesis runs alongside the straight-rail check; the old verdict still decides until the new one is qualified.

Technical noteHermite cubic from live SEP data + curvature bound; heartbeat counter proves execution.
TRACKER OT-5

Trust blurry data less

A spray-noise meter plugs in here. Until it arrives the scaling is exactly 1.00× — behavior identical.

Technical notef360_msmt_update_support_functions_ctca.cpp → Aprism_Entropy_Scale_WSE(); arm via Aprism_WSE_Feed(H,SNR).
TRACKER OT-6

Ghosts must show ID twice

A one-off blip can no longer associate as a ghost. It must appear two scans in a row — flicker is ignored.

Technical noteTwo-scan confirmation counter in the association hypothesis; resets on any miss.
ALIGNMENT DC-1

Start the day straight

Overnight-fleet computers used to start each run slightly crooked. The measured correction now loads before the first frame.

Technical noteTracker_VariantA_Wrapper.cpp: live dets_info.AutoAlign*/QF header transport wins; static Run-17 seed is once-only fallback.
ALIGNMENT DC-2

Sensors march in step

Each sensor stamps its own time. We now honor per-sensor timestamps and correct for ego-motion between them (sidecar only for now).

Technical notePer-sensor epochs from header timestamps; rigid-body deskew with live speed/yaw; max-|dt| recorder.
ALIGNMENT DC-3

Separate clock from bias

A wobbly clock can masquerade as a steering bias. A tiny two-target solver now splits the two apart without touching any output.

Technical noteAprism_DC_ClockTau1 / ClockTauBias2 / Clock_Update; consecutive-scan proxy until paired targets land.

04 ◆ Bugs we caught while finishing

Smart debugging paid off — five real defects found in the earlier draft and fixed in this session.

REAL BUG

The −1 that became 157

A "ghost handled" marker (−1) leaked into the log file, where it wrapped around to 157 out of 100. Now the marker is cleaned up every scan, with a safety clamp at the log itself.

HYGIENE

The notebook never erased

A per-scan checklist was never wiped between scans. Now it resets every cycle, so yesterday's ghosts can't haunt today.

STALE DATA

The frozen compass

The alignment correction was a hard-coded number re-applied every scan. Now the live measured value wins; the old number is only a one-time backup.

TIMING

All clocks read as one

Every sensor was stamped with the same time, hiding real skew — and the placeholder code peeked at not-yet-ready data. Now each sensor keeps its own timestamp with live motion data.

DEAD CODE

The dial connected to nothing

The spray-noise dial was hard-wired to "no change". It is now a real plug-in point the spray meter can drive — still exactly 1.00× until then.

PROCESS

No pushes, no surprises

All work stays in local working trees on three repos. Zero commits, zero pushes — reviewers get a clean, intentional diff.

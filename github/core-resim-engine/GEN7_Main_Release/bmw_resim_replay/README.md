# README

## CSV_IO_Library
Contains sources to read from a csv file.

## Documentation
Contains a static overview of components which shows the usage of a *ReplayFilter.*
Additionally there is a sequence diagram that shows the workflow of events used by the *ReplayFilter*.

## ReplayFilter
Contains sources of the *ReplayFilter*, used input and output interfaces. In this folder you can find another readme.md which describes the filter in more detail.

## Specification
Contains the reviewed (that is marked with comments, please open it in an appropriate tool)
specification document *Test_And_Validation_EM_ADAS_v3_reviewed.pdf*.

## Utils
Contains common source files not directly related to the *ReplayFilter* but used by it.

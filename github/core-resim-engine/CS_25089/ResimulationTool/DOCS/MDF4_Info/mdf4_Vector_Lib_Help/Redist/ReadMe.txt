Information for redistribution of MDF4 Lib
==========================================

The following prerequisites are necessary for distributing MDF4 Lib

1. Microsoft Visual C++ 2005 SP1 Redistributable
   Microsoft Visual C++ 2005 SP1 Redistributable should be available if Visual Studio 2005 SP1 is installed.


2. Microsoft XML Parser MSXML 6.0
   Microsoft XML Parser MSXML 6.0 is included with Windows Vista and Windows 7 and usually will be installed already on Windows XP by other tools.


In case one of the redistributables is missing, please find in the respective sub folder the setups for the 32 bit and the 64 bit versions.

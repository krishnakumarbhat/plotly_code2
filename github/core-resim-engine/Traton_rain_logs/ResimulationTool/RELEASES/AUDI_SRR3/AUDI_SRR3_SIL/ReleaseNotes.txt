------------------------------------
AUDI SRR3 SIL Release Notes
------------------------------------
This document provides a high level summary of changes since the previous Release, Patch, or
Update. For detailed change history, please refer to release notes in each directory.

Contents:
  The SRR3 components of this release/patch/update are provided in the following directories:
        ./AUDI_SRR3_SIL                    Software-in-Loop Binaries
        + LIB                             ; Libraries (32-bit and 64-bit)
        + INC                             ; API headers
        + DOC                             ; API description
        + CONFIG                          ; SIL configuration, DSD Calibration files, SRR3 sensor configuration etc

Components added/changed in this package will be denoted with (New) or (Updated).

--------------------------------------------------------------------------------------------------------------
     AUDI_SRR3_SIL_20160819
--------------------------------------------------------------------------------------------------------------
The package primarily support for AUDI SRR3 SW XY085 v3 SIL with RTE headers based on IF 0.7.5
Major components of this Release include:

  AUDI_SRR3_SIL\LIB

     + sil-srr3-audi.dll       		 45  (Updated)  ; Software-in-Loop Resimulation Library (64-bit)

 AUDI_SRR3SIL\DOC

     + AUDI_SRR3_SIL.doc  		 3.2  (Updated)  ; API documentation and sequence

 AUDI_SRR3SIL\CONFIG

     + DSD             		         7.1.1  (New)     ; DSD Calibration data
     + config_udp_frames.xml              7.0   (Updated) ; SRR3 SIL configuration file
 
       
Changes:
       
  
  [LIB]:
    - Fix: Exception thrown from SIL_SRR3_cleaup() API
    - Fix: Correction in Detection data decoding.
    - TEST: verified using ADTF XY085 Sandbox (20160810_Sbx_SRR_Analyse_SIL085v2)


Notes:
    - The SIL component has been tested on AUDI provided XY085 v3 sandbox
    - The SIL component has been tested with logs from XY085 and logs from previous sensor versions.
    - Replay of Logs/UDP stream from sensor SW prior XY085 version  will stop with an ERROR (due to mismatch in DSD version). The XY085 SIL package requires DSD data set version to be "7".Hence for the older data stream you need to set use the DSD only from XML [<Calibration_Source>XML</Calibration_Source>] and provide the version 7 DSD (the package has 7.1 DSD under Config\DSD\)
    - Enabled dumping OH and Track data from the SIL output to a CSV file (C:\SIL_LOG folder) only in DEBUG build SIL binaries(AUDI_SRR3_SIL\LIB\debug\x64)
    - Tested the SIL component using AUDI provided ADTF Sandbox with one dat file.
    - Provided sample source file "TestSILAPI.cpp" for the API sequence
    - SIL replay via Log would need a rewind only for the very first log (from a continuous mode log) once SIL engine has read all the calibration required for  
embedded SW under test
    - The package is build out from VS2010 with Windows7.1 SDK

Known Issues:
    - Please refer to \Doc\AUDI_SRR3_SIL.doc section 17.0 for Known Issues
    - There is a limitation on running SIL prior to XY058 using the current delivery.The CDC mode replay will NOT be functioning with the latest SIL delivery due to mismatch in the calibration required which is mandatory to generate valid Detection. And DETECTION mode replay WILL BE support though (with the usage of correct DSD configuration).

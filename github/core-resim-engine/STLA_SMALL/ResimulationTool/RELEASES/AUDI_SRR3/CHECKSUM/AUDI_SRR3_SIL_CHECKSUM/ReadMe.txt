READ-ME		MD5_AUDI_SRR3_EXECUTE.bat

Requirements for Running this bat
1.) MD5.exe
2.) fart.exe
3.) MD5_AUDI_SRR3_EXECUTE.bat

Process for Creating md5sum.sfv file
1.) Copy and paste the MD5_AUDI_SRR3_EXECUTE.bat, MD5.exe, fart.exe files from 'AUDI_SRR3_SIL_CHECKSUM' folder to outside of AUDI_SRR3_SIL folder.
2.) Click on the MD5_AUDI_SRR3_EXECUTE.bat file. This will execute the batch script and stores the created md5sum.sfv file, inside the AUDI_SRR3_SIL folder.


FAQ:

1.) Simple file verification (SFV) is a file format for storing CRC32 checksums of files to verify the integrity of files. SFV is used to verify that a file has not been corrupted, but it does not otherwise verify the file's authenticity. The .sfv file extension is usually used for SFV files.

2.) The MD5 checksum for a file is a 128-bit value, something like a fingerprint of the file. There is a very small possibility of getting two identical checksums of two different files. This feature can be useful both for comparing the files and their integrity control.

3.) FART is the Find And Replace Text command line utility.

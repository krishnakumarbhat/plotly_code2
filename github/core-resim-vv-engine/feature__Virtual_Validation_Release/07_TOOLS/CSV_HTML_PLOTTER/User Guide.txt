This CSV to HTML plotter is intended to plot the graphs of SM2 timing and LM2 timings from the timing profile 
csv file generated by the VV SiL Engine.

Instructions:
1. Open the command window from the folder where data.exe file is situated.
2. Enter the command: data.exe <absolute path of the timing profile csv file>
			 Example: data.exe "C:/user/123xyz/modelconfig_sil_CEER_With_FC_Satellite.yaml_TimingProfile.csv"
3. Output of this execution is an HTML file with name as "combined_timing_profile.html" and is formed in the same folder where the "data.exe" is executed.

----------------------------------------------------
CCA-Framework-MDF examples based on CCA-Framework-MDF v4.7.6
----------------------------------------------------
These examples demonstrates how to use the CCA-Framework-MDF in Python with the provided python library.
To run the examples, you need Python.


Examples:

cca-device
----------
This program demonstrates how to scan the network for cca devices and how to get a device by ip address.
It shows also some information about the found devices.

cca-download
------------
This program demonstrates how to download all recorded data from a logger or CopyStation to a local folder.
Usage:
cca-download.py [logger_ip] [local_folder]

cca-load-config
---------------
This program demonstrates how to upload a local config to a logger.
Usage:
cca-config.py <logger_ip> <config_folder>

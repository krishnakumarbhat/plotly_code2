Variables and their source in json files:

- angle_range is taken from   
	  if BMW_SRR7Plus or BMW_FLR7
		-90 to 90 hardcoded
	  else
		Hardware.Antenna.angle 
- antenna_gain_dB is taken from 
	  if BMW_SRR7Plus or BMW_FLR7
		Hardware.Antenna.k_Gain_Rolloff_Az_Reciprocal from usc_cal_2_72_0_3.json and convert to dB using -20log10(x)
		Hardware.Antenna.k_Gain_Rolloff_Az_Reciprocal from usc_cal_3_73_0_10.json and convert to dB using -20log10(x)
	  else
		Hardware.Antenna.azimuth but make sure to normalize(at boresight, 0degree) to 0dB before using in sensor model SMC
- Elevation Range is taken from 
	  if BMW_SRR7Plus or BMW_FLR7
		-90 to 90 hardcoded
	  else
		Hardware.Antenna.angle 
- elevation_gain_dB is taken from 
	  if BMW_SRR7Plus or BMW_FLR7
		Hardware.Antenna.k_Gain_Rolloff_EL_Reciprocal from usc_cal_2_72_0_3.json and convert to dB using -20log10(x)
		Hardware.Antenna.k_Gain_Rolloff_EL_Reciprocal from usc_cal_3_73_0_10.json and convert to dB using -20log10(x)
	  else
		Hardware.Antenna.elevation but make sure to normalize(at boresight, 0degree) to 0dB before using in sensor model SMC
- cc_range is taken from Processing.CFAR.correlation_coefficient
- cfar_offset_db is taken from 20*log10(Processing.CFAR.cfar_lut)
- k_temp_sens_dB is taken from 20*log10(Processing.Temperature.k_temp_sens)
- sens_thold_db is taken from Processing.RCS_Profile.rcs_profile_db
- sens_thold_range is taken from Processing.RCS_Profile.range_extended
- range_m, rcs_m_db, snr_m_db, snr_m_peak_db and temperature_m are parameters of manufacturing target as we need a reference SNR for Sensor Model
- doppler_sll is taken from -20*log10(SMC.Secondpass_Threshold.k_rwin_sll)
- k_end_rbin_CI is taken from 
	if BMW_SRR7Plus or BMW_FLR7
		Processing.CI.ci_stop_rbin
	else
		Processing.CI.end_rbin_CI
- k_start_rbin_CI is taken from 
	  if BMW_SRR7Plus or BMW_FLR7
		Processing.CI.ci_start_rbin
	  else
		Processing.CI.start_rbin_CI
- ci_gain_db is taken from 
	if BMW_SRR7Plus or BMW_FLR7
		Processing.CI.ci_cfar_offset
	else
		Processing.CI.CFAR_offset_CI_look_A. It is same for all looks
- K_Std_Range, K_Std_RR, K_Std_AZ_LUT, K_Std_El_LUT, K_Std_Max_SNR, K_Min_AZ_Zone_1, K_Max_AZ_Zone_1, Delta_AZ_Zone1, Delta_AZ_Zone2 and Delta_El are used for standard deviation calculation. This is still not implemented for Gen6.Note that K_Min_AZ_Zone_1, K_Max_AZ_Zone_1, Delta_AZ_Zone1, Delta_AZ_Zone2 and Delta_El are used in sensor model SMC in degrees
- Az_quality_LUT and Exist_Prob_Det_LUT are used for existence probability calculation. This is still not implemented for Gen6
- max_num_of_rbins is taken from Waveform.Look_X_Chirp.range_bins_used
- max_num_of_dbins is taken from Waveform.Look_X_Frame.Doppler_FFT_size
- radar_frequency is taken from Waveform.Look_X_Chirp.fc
- Look parameters are taken from Waveform.Look_X_Chirp.range_coverage, 
SMC.BW_Dependant_Thresholds.k_RBIN_RES_Look_X, 
SMC.Secondpass_Threshold.k_rdotmin,
SMC.Secondpass_Threshold.k_VUA_Look_X + SMC.Secondpass_Threshold.k_rdotmin, 
SMC.Secondpass_Threshold.k_DBIN_RES_Look_X, 
if SFW_V1
	SMC.BW_Dependant_Thresholds.k_rbin_bias_correction_factor_Look_X, 
	SMC.Secondpass_Threshold.k_primary_range_bin_freq_res_Look_X, 
	SMC.Secondpass_Threshold.k_secondary_freq_bin_res_Look_X, 
	SMC.Secondpass_Threshold.k_secondary_range_bin_res_Look_X, 
	SMC.Secondpass_Threshold.k_secondary_range_coverage_Look_X, 
	SMC.Secondpass_Threshold.k_primary_ranging_freq_Look_X, 
	SMC.Secondpass_Threshold.k_secondary_ranging_freq_Look_X, 
	SMC.Secondpass_Threshold.k_secondary_Doppler_freq_Look_X
if SfW_V2

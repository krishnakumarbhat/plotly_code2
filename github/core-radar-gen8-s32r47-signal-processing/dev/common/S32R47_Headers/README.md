spbb_S32R47_Common.h, spbb_S32R47_SPT.h are the SPBB local header equivalents of S32R47_Common.h, S32R47_mpu_armv7.h, S32R47_SPT.h. The MCAL repository has dependency to S32R47 Parent repo MCAL Config and OS Config so using the headers through the MCAL path causes dependency to parent repo and it is not necessary for the usage inside SPBB. So local copies of the header files are used for SPBB.

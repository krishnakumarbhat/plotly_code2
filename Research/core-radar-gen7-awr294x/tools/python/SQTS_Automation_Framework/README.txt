°Requirements to use the framework:
	-Python 3.10
	-Run "Dependency_Installer.bat" located in SQTS_Automation_Framework folder

°All tests included in the Testcases folder will be executed when you run the "Run_Test_Cases.bat" file, if you want a specific test case to be executed, move the remaining testcase files to another folder.

°In case you have multiple Python versions on your machine and bat file doesn't execute your cases then run "py RunTestCases.py" from the command prompt.

°Test examples can be found in the Testcases folder for CANoe, Trace32 and Power Supply Control.

°To run Power Supply related test cases, ensure that no other software that takes control over the power supply is running.

°For the version history of the framework please refer to https://confluence.asux.aptiv.com/display/STIG/Version+History

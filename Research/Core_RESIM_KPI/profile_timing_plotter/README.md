## Prerequisites
- Python 3.8 or higher
- Virtual environment (recommended)

## Packages
- Run `pip install -r requirements.txt`

## Command to run
`python timing_plotter.py folder_path.txt <OUTPUT_PATH>(Optional)`
- folder_path.txt : Provide the path till STATISTICAL_REPORT folder.
- <OUTPUT_PATH> : folder path where the results to be generated. If not given, then STATISTICAL_REPORT folder path will be taken as output path.

## Debugging
- Debug using `launch.json`

## .gitignore
- If any unwanted files are in Source control, Add those to .gitignore

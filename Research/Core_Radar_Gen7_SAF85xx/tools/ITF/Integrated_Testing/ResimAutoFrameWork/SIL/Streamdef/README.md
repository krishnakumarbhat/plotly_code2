# Streamdef Files for ITF Log Extraction

This folder is intended to store the streamdef files used during log-file extraction in ITF.

By default, ITF looks for streamdefs in:

`.\bazel-bin\outputs\variant\streamdefs`

If the streamdef location is not changed in ITF, the default path above will be used. Otherwise, you can copy the required streamdef files into this folder and point ITF to this location.
